## Real local inference

The separate model test (`pnpm test:models`) downloads pinned real model files through the UI into Cache Storage. It uses actual Transformers.js 3.8.1 and ONNX Runtime in workers, not provider stubs. Synthetic English and Italian WAV fixtures are generated speech.

- **All five models** (Fast, Balanced, High accuracy, Italian → English, English → Italian) were installed through the real UI from the real Hugging Face files. `pnpm verify:models` independently confirmed every pinned file's reachability, exact byte length and CORS readability for `https://3cn7.github.io`.
- Italian capture through `getUserMedia` → AudioWorklet → real Whisper tiny → real Italian-to-English OPUS translation was exercised for roughly 22 seconds with Pause/Resume/Stop. Original Italian, translations, chronological segment IDs and local raw audio were checked.
- After all network access was disabled and the page was reloaded, a real English upload was recognized by **Fast**, **Balanced** and **High accuracy**. Fast and Balanced produced "Today we will talk about Sicily, a region in southern Italy, the capital is Palermo."; High accuracy produced "…southern Italy. The capital is Palermo." (OPUS translation to Italian: "Oggi parleremo della Sicilia, regione del sud Italia, la capitale è Palermo.")
- Measured WebAssembly speed (one thread) on a 5.6 s clip on this Mac: Fast 1.9 s, Balanced 3.8 s, High accuracy 14.3 s, so High accuracy does not keep up with live speech.
- Automatic device selection was exercised offline earlier. The GPU loaded but produced incorrect output; the first-result CPU comparison selected WebAssembly. GPU acceleration is **not** claimed as working on this Mac.
- Mixed-language recognition and routing passed (Italian stayed Italian and translated; English stayed English with `same_language`), streaming capture from the saved audio (54,600 samples, RMS 0.181) passed, and the no-remote-inference-request assertion holds: permitted requests are GETs to Hugging Face hosts.

## Verification limits

The microphone is Chrome's synthetic input device carrying an actual speech waveform. A physical microphone, acoustic environment and OS microphone permission flow were not tested. No one-hour endurance test, real mobile browser/device test, native Chrome zoom-menu test, live Google account upload, audible-alert listening test, notification-delivery check or full assistive-technology audit was performed. Browser viewport/DPR emulation verifies reflow at the requested zoom factors. Token-based palettes and focus styles are implemented; automated layout assertions do not certify accessibility.

Whisper tiny made real recognition mistakes in some short/boundary phrases and proper names. The clearer US English fixture passed; the earlier voice sample misheard Sicily and Palermo. Local translations inherit recognition mistakes. Mixed switches within a chunk can be misclassified. Segment/sentence timing is approximate. Review and edit remain necessary. ONNX printed provider-partition warnings while exercising WebGPU; caught fallback and the final WASM results are reported separately from uncaught page exceptions.

The application migration backup is created on the user's first updated launch on the original site origin. Automated migration tests establish its behavior; no claim is made that the user's live browser database has already been backed up by these test profiles. No live Drive files were deleted, overwritten or migrated.

## Reproduce

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm test
pnpm build
pnpm dev
```

In another terminal, install Chromium once with `pnpm exec playwright install chromium`, then run `pnpm test:browser`. An existing Chrome can be selected with `STUDY_CHROME_PATH`. Run `pnpm test:models` for real model inference; it downloads about 650 MiB of models (all five) plus the runtime into an isolated profile (`STUDY_MODEL_PROFILE` selects one) and uses synthetic microphone input. `pnpm verify:models` needs internet and checks the pinned files against the live hosts. Delete that test profile only when you want to repeat its initial downloads.

Screenshots are written into ignored `test-results/`: dashboard, dark dashboard, populated mobile Flashcards, mobile study dialog and local translation. Source archives are readable only in the checkout; only the built public allowlist is served and deployed.
